Welcome to the Track Preseason. For those that are not in a winter sport and planning to do distance track it is a good idea to build a base to be prepared for the season to start. The preseason is for building mileage and strength not for hitting race pace. During the preseason the structure will be:

Monday - Steady Run/Long Run
Tuesday - Easy Run
Wednesday - Hills Sprints/Plyos
Thursday - Easy Run
Friday - Tempo Workout
Saturday - Easy Run

Based on how often you are able to run in a week here are some sample plans.

Runner A - Can run at least 4 times a week.

|Week|Monday|Tuesday|Wednesday|Thursday|Friday|Saturday|Sunday|
|1|30 Minutes Easy|30 Minutes Easy|Plyos|30 Minutes Easy|4 x 3 minute tempo|30 Minutes Easy|Off|
